Cómo funciona

Reglas locales y resultados orientativos

Todos los módulos se ejecutan dentro de este archivo. Los resultados son demostrativos y no sustituyen verificación humana ni herramientas profesionales.

1. Entrada

El usuario escribe, pega o selecciona un ejemplo de mensaje, cédula o imagen.

2. Validación

JavaScript local revisa patrones de riesgo, estructura documental o metadatos preventivos.

3. Puntuación

Las señales detectadas se convierten en una puntuación de 0 a 100 y un nivel bajo, medio o alto.

4. Recomendación

La interfaz explica por qué hay riesgo y sugiere pasos seguros sin afirmar certeza absoluta.
