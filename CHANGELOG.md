# Changelog

Todas las notas relevantes del proyecto se documentan en este archivo.

## [1.0.0] - 2026-08-18

- Organizacion inicial del repositorio `phishingwall-ai`.
- Implementacion de aplicacion web estatica para analisis de mensajes y enlaces.
- Incorporacion de seccion visible "Prueba PhishingWall AI" con ejemplos rapidos ficticios.
- Incorporacion de modo demostracion local deterministico cuando no hay servicios externos configurados.
- Incorporacion de LANA para validacion local de cedula ecuatoriana con proteccion visual.
- Incorporacion de demostracion de privacidad con codigo local `DEMO2026` y datos no reales.
- Incorporacion de AURELIO para revision local de imagenes por nombre, formato y tamano.
- Incorporacion de imagen local ficticia para probar AURELIO.
- Agregada documentacion principal, licencia propietaria, aviso legal y politica de seguridad.
- Agregadas pruebas de humo y revision estatica de secretos.
- Conservado `phishingwall.psc` como material historico en `docs/legacy/`.
