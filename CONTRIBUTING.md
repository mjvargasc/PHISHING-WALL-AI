# Contribuciones

PhishingWall AI es un proyecto cuyos componentes originales tienen como titular a Mathias Javier Vargas Caicedo, creador, autor y desarrollador principal. Las contribuciones requieren autorización del titular antes de ser incorporadas.

## Reglas basicas

- No incluir secretos, tokens, credenciales, cookies, historiales privados ni datos personales reales.
- Mantener el enfoque educativo y preventivo del proyecto.
- No presentar resultados como garantia absoluta de seguridad.
- Pedir confirmacion antes de agregar dependencias de produccion.
- Actualizar README, CHANGELOG y documentacion cuando cambie el comportamiento.
- Ejecutar `npm run check` antes de proponer cambios.

## Flujo sugerido

1. Crear una rama descriptiva.
2. Realizar cambios pequenos y verificables.
3. Ejecutar pruebas y revisiones estaticas.
4. Revisar que `.env` y credenciales no esten incluidos.
5. Solicitar revisión de Mathias Javier Vargas Caicedo como titular de los componentes originales del proyecto.
